### Actividad Extraordinaria  

Este repositorio contiene la actividad de GitHub y Git, organizada por unidades. Está estructurado de manera clara para facilitar el acceso a los temas aprendidos en cada sección.  

### Estructura  

Unidad1: Introducción al sistema binario, lógica y algoritmos. Explica cómo funcionan los números binarios en las computadoras, las operaciones lógicas utilizadas en programación y el concepto de algoritmo como base para la resolución de problemas computacionales.  

Unidad2: Tipos de datos, operadores y estructuras de control. Presenta los distintos tipos de datos utilizados en programación, los operadores matemáticos y lógicos, así como las estructuras de control condicionales y los bucles, que permiten crear programas dinámicos.  

Unidad3: Uso de Git y GitHub, comandos básicos y ejemplos. Explica la importancia del control de versiones, el uso de Git para gestionar proyectos y la manera en que GitHub facilita la colaboración en el desarrollo de software.  

### Cómo clonar este repositorio  

Para descargar una copia local de este repositorio, se debe ejecutar el siguiente comando en la terminal:  

git clone https://github.com/antu-velasquez/ActividadExtraordinaria.git  

Esto permitirá trabajar con los archivos en el equipo local y realizar modificaciones si es necesario.  

### Flujo de trabajo en Git  

Para agregar cambios y actualizarlos en GitHub, se deben seguir estos pasos:  

1. Ubicarse en la carpeta del repositorio:  
   cd ActividadExtraordinaria  

2. Crear una nueva rama para trabajar en modificaciones sin afectar la versión principal:  
   git checkout -b nueva-rama  

3. Agregar los archivos modificados al área de preparación:  
   git add .  

4. Confirmar los cambios con un mensaje que describa las modificaciones realizadas:  
   git commit -m "Descripción de los cambios"  

5. Subir los cambios a GitHub:  
   git push origin nueva-rama  

Si los cambios deben integrarse a la versión principal, se puede crear una solicitud de extracción en GitHub para fusionar las modificaciones con la rama principal del proyecto.
